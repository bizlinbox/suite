# BizlInbox – WhatsApp Cloud API Based Inbox

## Core Objective

A multi-tenant WhatsApp inbox platform built on the WhatsApp Cloud API, enabling businesses to:

-   Receive WhatsApp messages
-   Reply from a shared inbox
-   Assign conversations to agents
-   Manage contacts
-   Use canned responses
-   Automate workflows
-   Track analytics
-   Support multiple WhatsApp numbers

## Technology Stack

### Frontend
-   Next.js (App Router)
-   MUI / Joy UI
-   Axios
-   Socket.IO Client

### Backend
-   Node.js
-   Express.js

### Database
-   PostgreSQL

### Queue System
-   Redis
-   BullMQ

### Realtime
-   Socket.IO

### Storage
-   Local Storage / S3 Compatible Storage

### Authentication
-   JWT + Refresh Tokens
-   HttpOnly Cookies
